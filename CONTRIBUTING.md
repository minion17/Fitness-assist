# Как вносить изменения

1. Новая ветка от свежего `main`: `git checkout main && git pull && git checkout -b имя-задачи`
2. Изменения + коммит, затем `git push -u origin имя-задачи`
3. На GitHub открыть Pull Request в `main`. Автоматически запустятся тесты (вкладка Checks).
4. Слияние — после зелёных тестов и ревью.

## Данные (`content/`)

Продукты, упражнения и программы — JSON в `content/` (форматы в README, раздел «Данные и журналы»).
Достаточно изменить JSON: при запуске `start.bat` новые записи сами попадут в базу. Код для этого менять не нужно.
Упражнение, упомянутое в программе, должно быть в `exercises.json` с точно таким же названием — иначе импорт остановится с понятной ошибкой.

## Код

- Модели — `backend/database/models.py`, API — `backend/api/main.py`. Не дописывать код в файлы скриптами.
- XP начислять только через `award_xp(...)` с событием из `RULES` в `backend/core/gamification.py`.
- Новая логика — с тестом в `tests/`. Локально: `pytest` (нужна база `fitness_test`) и `cd frontend && npm test`.
